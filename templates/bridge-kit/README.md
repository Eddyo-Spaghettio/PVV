# Bridge Kit - Client Deliverable Templates

Copy these into the client's folder in the shared PVV Drive. Customize bracketed fields.

---

## 1. Reach Page Content Template

Use this to gather info before building the Google Site.

```
ORGANIZATION NAME: [e.g., Ecumenical Hunger Program]
TAGLINE (one sentence): [e.g., Neighbors helping neighbors in East Palo Alto since 1975]

MISSION (2-3 sentences):
[What they do, who they serve, why it matters]

VOLUNTEER SIGN-UP FORM URL: [Google Form link]
DONATE URL: [Givebutter / PayPal / Venmo link]
INSTAGRAM: [@handle]
FACEBOOK: [page URL]
CONTACT EMAIL: [info@org.org]
PHONE: [(650) xxx-xxxx]
ADDRESS: [physical location]

VOLUNTEER OPPORTUNITIES (list 2-3): - [e.g., Food sorting - Saturdays 9am–12pm] - [e.g., Event setup - monthly]

IMPACT STAT (one number): [e.g., 200 families served weekly]
```

## 4. 90-Day Content Calendar Structure

See `90-day-calendar-template.csv` for the full spreadsheet.

**Posting cadence:** 2–3 posts per week
**Content mix:** - Week 1–2: Introduce the org + one impact story - Week 3–4: Promote upcoming event or volunteer need - Week 5–8: Behind-the-scenes, volunteer spotlight, education post - Week 9–10: Event recap or countdown - Week 11–12: Thank you + "stay involved" call to action
